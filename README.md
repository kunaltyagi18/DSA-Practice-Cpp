## 🎯 Study Plan

### Week 1-2: Arrays & Strings
Focus on fundamental array and string manipulation techniques, two pointers, and sliding window.

### Week 3-4: Linked Lists & Trees
Master linked list operations and tree traversal techniques (DFS, BFS).

### Week 5-6: Dynamic Programming
Build strong foundation in DP patterns and memoization.

### Week 7-8: Graphs & Advanced Topics
Practice graph algorithms, backtracking, and system design patterns.

## 💡 Key Patterns to Master

1. **Two Pointers** - Arrays, Strings, Linked Lists
2. **Sliding Window** - Arrays, Strings
3. **Fast & Slow Pointers** - Linked Lists, Cycle Detection
4. **Merge Intervals** - Interval problems
5. **Cyclic Sort** - Array problems with numbers in range
6. **In-place Reversal** - Linked Lists
7. **Tree BFS/DFS** - Binary Trees
8. **Topological Sort** - Graphs
9. **Binary Search** - Sorted arrays
10. **Top K Elements** - Heaps
11. **K-way Merge** - Multiple sorted arrays
12. **Dynamic Programming** - Optimization problems
13. **Backtracking** - Combinations, Permutations
14. **Bit Manipulation** - XOR, AND, OR operations
